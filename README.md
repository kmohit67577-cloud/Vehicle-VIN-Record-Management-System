# Vehicle VIN Record Management System

## Project Overview
A C-based console application for managing vehicle
records using simulated VIN generation and file handling.

## Technologies
- C Programming Language
- GCC Compiler
- Visual Studio Code
- Standard C Libraries

## Main Features
1. Vehicle Registration
2. VIN Generation
3. VIN Validation
4. Vehicle Search
5. Vehicle Update
6. Vehicle Deletion
7. Record Sorting
8. Vehicle Statistics
9. File Handling
